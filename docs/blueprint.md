# **App Name**: Dwimulya Hub

## Core Features:

- Academic Programs: Displays a list of all academic programs available.
- Admissions Information: Provides a guide for students to understand admission requirements, steps and deadlines.
- News and Events: Displays latest news, events, and announcements relevant to the STIE Dwimulya community.
- Core Values Showcase: Showcases the STIE Dwimulya core values of Empowerment and Change, with prominent messaging of 'Kampus Rakyat Kampus Perubahan'.
- Contact form: Simple contact form for user enqueries

## Style Guidelines:

- Primary color: Golden Rod (#DAA520), to convey prestige and aspiration.
- Background color: Broken White (#F5F5DC), providing a clean and modern backdrop that ensures readability.
- Accent color: Oxford Blue (#002147), used sparingly for key interactive elements, providing a professional and academic tone.
- Body font: 'PT Sans' sans-serif for readability and a modern touch.
- Headline font: 'Playfair' sans-serif font, a font pairing is recommended to add a stylish, sophisticated touch, well-suited for headlines or shorter texts.
- Crisp, modern icons that reflect academic disciplines and campus life, in Oxford Blue, for visual clarity.
- A clean, grid-based layout that ensures content is well-organized and easily accessible, providing an intuitive user experience.
